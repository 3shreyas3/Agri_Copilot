SECTION IV: METHODOLOGY AND CORE MATHEMATICAL ENGINES

This section formalizes the mathematical models, algorithmic pipelines, and computational formulations implemented across the core intelligence engines of AgriCopilot. The methodology spans six interconnected subsystems: in-browser pedological computer vision, biophysical agrometeorological stress modeling, dynamic alternate crop suitability scoring, supply-elasticity market forecasting, geospatial highway freight arbitrage logistics, and two-tier land-segmented institutional credit triage.


A. In-Browser Pedological Computer Vision Classifier

The perception pipeline executes directly within the browser runtime using HTML5 Canvas memory buffers, operating on client-side pixel arrays without transmitting raw imagery to remote cloud servers.

1. Adaptive 5-Zone Spatial Pooling and Outlier Rejection:
Handheld agricultural field photographs frequently contain non-soil artifacts, including user fingers, lens vignetting, harsh sunlight glares, and deep shadow crevices. To isolate authentic pedological pixels, the analyzer in soilImageAnalyzer.js executes an adaptive spatial segmentation:
- Luminance Filtration: For each pixel with sRGB coordinates, perceptual luminance is calculated as:
  Luminance = 0.299 * R + 0.587 * G + 0.114 * B
  Pixels with Luminance below 10 (underexposed deep shadows) or above 245 (specular solar glare) are discarded.
- Spatial Region Weighting: The active image canvas of width W and height H is partitioned into an inner region of interest and outer boundaries:
  Center Region: x in [0.25 * W, 0.75 * W] and y in [0.25 * H, 0.75 * H]
  Outer Region: x, y outside the center boundary.
- Weighted Channel Pooling: Mean color channel intensities are computed with a center-weighted distribution:
  C_bar = (C_center_mean * 0.65) + (C_outer_mean * 0.35)   for C in {R, G, B}
  This spatial formulation ensures that peripheral hand interference is minimized while prioritizing the central soil clod structure.

2. Device-Independent CIE-Lab Color Space Conversion:
Raw sRGB color spaces are device-dependent and perceptually non-linear. To establish rigorous alignment with the Munsell Soil Color Charts (the global pedological taxonomy standard), sRGB values are transformed into the perceptually uniform CIE-Lab color space under standard CIE D65 illuminants:
- Step 1: Gamma Linearization of sRGB:
  C_lin = C / 12.92                                 if C <= 0.04045
  C_lin = ((C + 0.055) / 1.055)^2.4                 if C > 0.04045
  where C in { R_bar / 255, G_bar / 255, B_bar / 255 }
- Step 2: Forward Matrix Transformation to CIE XYZ (D65 Reference White Point):
  X = (0.4124564 * R_lin + 0.3575761 * G_lin + 0.1804375 * B_lin) / 0.95047
  Y = (0.2126729 * R_lin + 0.7151522 * G_lin + 0.0721750 * B_lin) / 1.00000
  Z = (0.0193339 * R_lin + 0.1191920 * G_lin + 0.9503041 * B_lin) / 1.08883
- Step 3: Non-Linear Cube-Root Function f(t):
  f(t) = t^(1/3)                if t > 0.008856
  f(t) = 7.787 * t + (16 / 116)  if t <= 0.008856
- Step 4: Orthogonal CIE-Lab Coordinates:
  L* = max(0, 116 * f(Y) - 16)      [Perceptual Lightness: 0 to 100]
  a* = 500 * (f(X) - f(Y))          [Green (-) to Red (+) chromaticity; ferric iron proxy]
  b* = 200 * (f(Y) - f(Z))          [Blue (-) to Yellow (+) chromaticity; quartz sand proxy]

3. 9-Dimensional Pedological Feature Extraction Vector:
From the linearized spatial image data, the engine extracts a 9-dimensional representation vector encapsulating colorimetric, mineralogical, and structural traits:
- f1 = L* (Perceptual Lightness)
- f2 = a* (Red-Green axis quantifying ferric iron hematite Fe2O3 concentration)
- f3 = b* (Yellow-Blue axis quantifying quartz sand and goethite content)
- f4 = Hematite Redness Index (RI):
  RI = (R_bar - G_bar) / (R_bar + G_bar + 0.001)
  Hematite strongly absorbs green spectra while reflecting red wavelengths; high RI uniquely differentiates Alfisols (Red soils) and Oxisols (Laterites).
- f5 = Soil Organic Carbon Index (SOC):
  SOC = (100 - L*) / 100
  Organic humus absorbs light evenly across visible spectra; dark soils with low L* yield high SOC indices characteristic of fertile Vertisols (Black Regur).
- f6 = Spatial Laplacian Texture Roughness:
  Roughness = ( (1 / (N - 1)) * sum(|Luminance(x + 1, y) - Luminance(x, y)|) ) * 1.8
  This computes gradient variance across neighboring pixels, differentiating coarse, cloddy soil structures from smooth, finely ground silts.
- f7, f8, f9 = Gray-World Illuminant-Invariant Normalized Chromaticities:
  r_norm = R_bar / (R_bar + G_bar + B_bar)
  g_norm = G_bar / (R_bar + G_bar + B_bar)
  b_norm = B_bar / (R_bar + G_bar + B_bar)
  These cancel out ambient sunlight intensity variations across direct sun and overcast conditions.

4. Calibrated Centroid Distance and Temperature-Scaled Softmax Classification:
The 9-dimensional feature vector is classified across six ICAR-NBSS&LUP soil orders (black, red, laterite, sandy_loam, clayey, and alluvial). For each candidate soil class k, class centroid weights (w_i,k) and empirical tolerance variances (tol_i,k) are defined in trainedSoilModel.js.
- Dimensionally Weighted Scaled Distance Metric:
  dL = ((L* - w_L,k) / tol_L,k)^2
  da = ((a* - w_a,k) / tol_a,k)^2
  db = ((b* - w_b,k) / tol_b,k)^2
  dRI = ((RI - w_RI,k) / tol_RI,k)^2
  dr = ((r_norm - w_r,k) / tol_r,k)^2
  dg = ((g_norm - w_g,k) / tol_g,k)^2
  db_norm = ((b_norm - w_b,k) / tol_b,k)^2
  dSOC = ((SOC - w_SOC,k) / tol_SOC,k)^2
  dRough = ((Roughness - w_Rough,k) / tol_Rough,k)^2

  Total Distance D_k = sqrt(
    dL * 1.8 +
    da * 2.2 +
    db * 1.6 +
    dRI * 2.0 +
    dr * 1.2 +
    dg * 1.0 +
    db_norm * 1.0 +
    dSOC * 1.2 +
    dRough * 0.8
  )
  Weights reflect pedological discriminatory power: a* and Redness Index receive the highest weights (2.2 and 2.0) because ferric iron concentration provides the highest taxonomic separability.
- Temperature-Scaled Softmax Probability Distribution:
  With temperature hyperparameter T = 1.3:
  Exponential Score S_k = exp(-D_k / T)
  Probability P(Class_k) = round( (S_k / sum_j(S_j)) * 100 )
  The temperature parameter prevents overconfident probability saturation on borderline samples. The classifier ranks all classes, identifies top predictions and runner-up confidences, and automatically flags a Visual Soil Mismatch if the photo-predicted soil order contradicts the farmer-selected soil order.


B. Agrometeorological Biophysical Stress Modeling

Grounded in ICAR agronomic thresholds, the advisory engine in advisoryEngine.js computes continuous non-linear biophysical stress scores for the cultivated crop across thermal, hydrological, and edaphic dimensions.

1. Physiological Cardinal Thermal Bounds:
For each crop with physiological minimum (T_min), maximum (T_max), and optimal (T_opt) temperatures:
- Optimal Thermal Range (T_min <= T <= T_max):
  diff_opt = |T - T_opt|
  Score S_temp = max(75, round(100 - (diff_opt * 2.5)))
  Penalty P_temp = (diff_opt > 4) ? 0.5 : 0
- Severe Cold Shock (T < T_min):
  deficit_T = T_min - T
  If deficit_T >= 6 degrees:
    S_temp = max(10, round(50 - (deficit_T * 7)))
    Penalty P_temp = min(4.2, 2.0 + deficit_T * 0.4)
  Else:
    S_temp = max(25, round(75 - (deficit_T * 7)))
    Penalty P_temp = min(2.0, deficit_T * 0.35)
- Extreme Heat Stress (T > T_max):
  excess_T = T - T_max
  If excess_T >= 5 degrees:
    S_temp = max(10, round(50 - (excess_T * 7)))
    Penalty P_temp = min(4.5, 2.0 + excess_T * 0.45)
  Else:
    S_temp = max(25, round(75 - (excess_T * 7)))
    Penalty P_temp = min(2.2, excess_T * 0.35)
  High thermal penalties specifically account for heat-induced pollen sterility, flower abortion, and leaf scorching during anthesis.

2. Hydrological Moisture Balance and Soil Order Compatibility:
- Optimal Moisture Range (R_min <= R <= R_max):
  diff_rain = |R - R_opt|
  Score S_rain = max(75, round(100 - ((diff_rain / 200) * 10)))
  Penalty P_rain = 0
- Acute Drought Deficit (R < R_min):
  deficit_R = R_min - R
  percent_deficit = round((deficit_R / R_min) * 100)
  If percent_deficit >= 35%:
    S_rain = max(10, round(50 - (percent_deficit * 0.6)))
    Penalty P_rain = min(4.5, 2.0 + (percent_deficit / 100) * 3.5)
  Else:
    S_rain = max(25, round(75 - ((deficit_R / 150) * 15)))
    Penalty P_rain = min(2.2, (deficit_R / 150) * 1.8)
- Waterlogging Excess (R > R_max):
  excess_R = R - R_max
  percent_excess = round((excess_R / R_max) * 100)
  If percent_excess >= 40%:
    S_rain = max(15, round(50 - (percent_excess * 0.5)))
    Penalty P_rain = min(4.2, 1.8 + (percent_excess / 100) * 2.5)
  Else:
    S_rain = max(25, round(75 - ((excess_R / 200) * 15)))
    Penalty P_rain = min(2.0, (excess_R / 200) * 1.5)
- Soil Order Compatibility:
  If crop ideal soil: S_soil = 100, Penalty P_soil = 0
  If compatible soil family: S_soil = 80, Penalty P_soil = 1.2
  If incompatible soil order: S_soil = 35, Penalty P_soil = 2.8

3. Composite Plant Health Score and Risk Penalty Formulation:
The continuous composite Plant Health Score (scaled 1.0 to 10.0) integrates baseline vitality against accumulated biophysical and visual penalties:
HealthScore = 8.5 - P_soil - P_temp - P_rain - P_mismatch
where P_mismatch = 1.6 if a contradiction exists between farmer-stated soil and photo classification.
The raw score is clamped within viable biological boundaries:
HealthScore = clamp(2.0, 9.8, HealthScore)
The composite health percentage presented to the farmer is derived as:
HealthScorePercent = round(HealthScore * 10)   [Clamped between 20% and 98%]
Risk levels are categorized into Low, Medium, and High based on threshold triggers: HealthScore below 6.0, the presence of severe stress triggers, or three or more cumulative risk factors marks the crop as High Risk.


C. Resilient Alternate Crop Suitability and 1-Click Adaptive Switching

When an initial crop evaluation flags High Risk, AgriCopilot executes an automated mitigation protocol rather than issuing uninformative rejection alerts.

1. Multi-Criteria Suitability Scoring Equation:
The engine iterates across all candidate crops in the agronomic database, evaluating each candidate against the farmer's specific field conditions (soil order, temperature, and rainfall):
Suitability Score = (S_soil * 0.40) + (S_rain * 0.35) + (S_temp * 0.25)
Weights reflect biological survivability: soil texture and moisture retention account for 75% of total viability because poor soil-water dynamics cannot be easily rectified in open-field farming.

2. Dynamic Pareto Ranking and 1-Click Mitigation:
Candidate crops are ranked in descending order of Suitability Score. The system filters out candidates suffering from severe stress and selects the top three resilient alternatives. For each alternative, the engine calculates:
- Projected Health Score under field conditions.
- Explicit justification advantages (e.g., Drought Resilient: requires only 450mm rainfall versus 1200mm for Paddy).
- Minimum Support Price (MSP) economic assurance.
- The 1-Click Adaptive Switch: The user interface binds the highest-ranked alternative to an atomic state update. When clicked, the application automatically substitutes the crop input, triggers local re-evaluation, and transitions the farm plan from High Risk (<50%) to an optimal healthy plan (>=90% health score).


D. APMC Sowing Saturation Elasticity and Mandi Price Forecasting

To mitigate the post-harvest Cobweb Phenomenon, the economic engine models wholesale price trajectories as a function of regional sowing popularity percentage (P_sow).

1. Regional Sowing Popularity Elasticity Multiplier:
- Market Glut Regime (P_sow > 80%):
  When more than 80% of district farmers sow the identical crop, simultaneous harvest arrivals cause severe local oversupply. The engine applies a deflationary price multiplier:
  lambda_min = 0.78,  lambda_max = 0.85
  This projects an expected 15% to 22% wholesale price crash and issues an Over-Supply Glut Warning.
- Scarcity Premium Regime (P_sow < 35%):
  When regional cultivation is low, local supply shortages allow farmers to command premium prices:
  lambda_min = 1.15,  lambda_max = 1.28
  This projects a 15% to 28% price surge and signals high market demand.
- Balanced Market Regime (35% <= P_sow <= 80%):
  Production matches historical consumption patterns:
  lambda_min = 0.95,  lambda_max = 1.08
  Wholesale prices fluctuate steadily around baseline mandi modal averages.

2. Predicted Wholesale Mandi Price Band:
Given baseline minimum (P_base,min) and maximum (P_base,max) historical mandi rates from Agmarknet:
Predicted_Min_Price = round(P_base,min * lambda_min)
Predicted_Max_Price = round(P_base,max * lambda_max)
Predicted Price Range = [Predicted_Min_Price, Predicted_Max_Price] INR per Quintal


E. Geospatial Logistics and Interstate Mandi Arbitrage Engine

When local mandis face severe price crashes due to oversupply gluts, the market redirection module in marketRedirectionData.js identifies high-demand deficit terminal markets in neighboring states.

1. Spherical Haversine Distance and Highway Tortuosity:
Between the origin farming district (lat1, lon1) and candidate destination terminal mandis (lat2, lon2), the great-circle angular distance is computed:
dLat = ((lat2 - lat1) * pi) / 180
dLon = ((lon2 - lon1) * pi) / 180

a = sin^2(dLat / 2) + cos(lat1 * pi / 180) * cos(lat2 * pi / 180) * sin^2(dLon / 2)
c = 2 * atan2(sqrt(a), sqrt(1 - a))
Straight_Line_Distance = R * c   [where Earth radius R = 6371 km]

Real-world highway networks deviate from straight-line geodesic paths due to terrain contours and bypass routing. An empirical road tortuosity factor of 1.28 (calibrated for Indian National Highway corridors NH 48, NH 44, and NH 75) is applied:
Road_Distance_Km = round(Straight_Line_Distance * 1.28)

2. Freight Logistics Cost and Net Arbitrage Margin:
Commercial diesel trucking rates across interstate transport corridors are modeled as:
Freight_Cost_Per_Quintal = round((Road_Distance_Km / 100) * 36 + 22)  [INR per Quintal]
where 36 INR per 100 km represents standard fuel and haulage rates, and 22 INR accounts for base terminal handling and toll overhead.
- Economic Arbitrage Metrics:
  Gross Spread per Quintal = Destination Mandi Price - Local Depressed Mandi Price
  Net Arbitrage per Quintal = Gross Spread per Quintal - Freight Cost per Quintal
  Total Lot Net Gain = round(Net Arbitrage per Quintal * Lot_Size_Quintals)
  Return on Investment (ROI %) = round((Net Arbitrage per Quintal / Local Depressed Price) * 100)
  Transit Duration (Hours) = round(Road_Distance_Km / 42)  [based on 42 km/h commercial truck average]
If Net Arbitrage is positive, the system generates an interactive Leaflet map polyline routing produce from the depressed local mandi to the destination deficit terminal hub (e.g., Davanagere to Mumbai Vashi or Pune).


F. Two-Tier Land-Segmented Institutional Credit and Policy Portal

Financial guidance is dynamically segmented based on the farmer's operational landholding size (A) to prevent inappropriate loan applications and informal debt traps.

1. Marginal Smallholders (A < 2.0 Acres):
Smallholder cultivators are routed to micro-credit and subsidized revolving facilities:
- Kisan Credit Card (KCC): Subsidized 4.0% per annum effective interest rate (7.0% base rate minus 3.0% prompt repayment incentive subvention).
- Collateral-Free Credit Limit: Up to 1.6 Lakh INR (expandable to 3.0 Lakh INR with land tie-up).
- Group Lending: PM MUDRA Shishu loans and Joint Liability Group (JLG) peer-guaranteed credit for tenant cultivators.
- Welfare Entitlements: Direct integration with PM-KISAN (6,000 INR/year direct benefit transfer) and PMFBY subsidized crop insurance.

2. Commercial Cultivators (A >= 2.0 Acres):
Medium and large-scale commercial growers are directed to medium-to-long term capital development programs:
- Agriculture Infrastructure Fund (AIF): Term credit up to 2 Crore INR with a 3.0% interest subvention for establishing on-farm cold storages, sorting units, and ripening chambers.
- Electronic Negotiable Warehouse Receipts (e-NWR): Produce pledge financing up to 75% of market value under WDRA-registered warehouses, enabling farmers to withhold produce during harvest gluts and sell during off-season price recoveries.
- Post-Harvest Value Addition Simulator:
  Calculates margin expansion unlocked through primary on-farm grading, cleaning, and packaging:
  Raw_Revenue = Harvest_Yield_Quintals * ((Predicted_Min + Predicted_Max) / 2)
  Processed_Revenue = round(Raw_Revenue * (1 + (Boost_Percentage / 100)))
  Extra_Net_Profit = Processed_Revenue - Raw_Revenue
  Demonstrating that primary processing yields a 20% to 35% margin boost over raw auction sales.
